# 이미지 용량 압축기

여러 장의 이미지를 JPG 또는 WebP로 변환하면서 용량을 줄이는 웹 도구입니다. `index.html` 파일 하나로 동작하며, 모든 처리는 브라우저 안에서만 이루어집니다. 이미지는 서버로 전송되지 않습니다.

## 맞출 기준 (세 가지 모드)

- **장당 용량**: 한 장마다 목표 용량(예: 200KB)을 넘지 않는 범위에서 가장 높은 화질을 찾습니다.
- **전체 용량**: 모든 사진의 합계를 목표 용량(예: 500장 → 100MB) 이하로 맞춥니다. 먼저 사진마다 화질별 용량을 측정한 뒤, 합계가 예산 안에 드는 가장 높은 공통 화질을 계산합니다. 복잡한 사진은 용량을 더 쓰고 단순한 사진은 덜 씁니다.
- **화질 보장**: 원본과 결과를 SSIM으로 비교해서, 선택한 기준(눈으로 차이 없음 등)을 통과하는 가장 작은 파일을 고릅니다.

## 그 밖의 기능

- MozJPEG 인코더(WebAssembly, 파일 안에 포함): 같은 용량 안에서 JPG 화질을 더 높입니다.
- 최대 크기(긴 변) 제한, 화질 하한 설정 (하한으로도 안 되면 해상도를 줄임)
- 다시 저장하면 오히려 커지는 사진은 원본을 그대로 둡니다.
- 여러 CPU 코어를 동시에 사용하고, 결과를 ZIP으로 한 번에 저장할 수 있습니다.

## 사용한 오픈소스

- [mozjpeg](https://github.com/mozilla/mozjpeg) (BSD 계열 라이선스), [jSquash](https://github.com/jamsinclair/jSquash)의 WebAssembly 빌드 (Apache-2.0)
- [JSZip](https://stuk.github.io/jszip/) (MIT, CDN에서 불러옴)
